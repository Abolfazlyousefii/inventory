# کالاهای پرفروش

گزارش مستقل و فقط خواندنی در `/finance/reports/top-products` با دسترسی موجود «گردش حساب و گزارش مالی».

- فقط `invoices.status = shipped` و `cancelled_at IS NULL`، با بازهٔ شامل روز اول و آخر روی `shipped_at`؛ پیش‌فرض از ابتدای ماه شمسی تا امروز.
- فاکتور ارسال‌شدهٔ بدون تاریخ ارسال وارد بازه نمی‌شود؛ تعداد این موارد در کل سوابق منطبق با فیلترها هشدار داده می‌شود. تاریخ ایجاد جایگزین نمی‌شود.
- تعداد / مبلغ، کالا / تنوع، دسته با فرزندان، فروشنده طبق `Invoice::effectiveSellerSql`.
- قیمت تاریخی ردیف، تخفیف ردیف و تخفیف سند طبق `SalesDocumentTotals::fromDocument`. تخفیف اضافی سند با تخصیص تجمعی روی تمام ردیف‌های همان سند محاسبه می‌شود تا جمع ریال حفظ شود؛ سپس فیلتر کالا اعمال می‌شود. تخفیف از پیش تخصیص‌یافته دوباره کم نمی‌شود. ارسال و مرجوعی محاسبه نمی‌شوند.
- موجودی فعلی: جمع `warehouse_stocks.quantity` در انبار مرکزی یکتا، بدون کسر مجدد رزرو. ردیف بدون تنوع کالای دارای تنوع دوباره جمع نمی‌شود. موجودی تاریخی روز ارسال نیست.
- نمودار میله‌ای ۱۰ مورد اول؛ حلقه‌ای ۵ مورد و سایر موارد با رنگ‌های ثابت مشترک؛ جدول صفحه‌بندی‌شده، جزئیات تنوع، روز ارسال و فاکتورهای مرتبط. لینک فاکتور تابع مجوز و مالکیت موجود است.
- اکسل واقعی XLSX با رشته‌های صریح (جلوگیری از فرمول نام کالا)، چاپ و ذخیره PDF از مرورگر با فونت وزیر، مطابق فیلترها و هشدار سوابق بدون تاریخ.
- بدون migration، تغییر موجودی، رزرو، پرداخت، پورسانت یا اصلاح تاریخ‌های قبلی.

اعتبارسنجی: تست‌های مستقل SQLite برای مرز تاریخ ارسال، مالک فروش، دسته‌های فرزند، تخفیف‌ها، جمع مبلغ، موجودی آزاد، دسترسی، تاریخ نامعتبر، ماه شمسی، اکسل، چاپ و نداشتن نوشتن روی دیتابیس. تست مرورگر در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۳۶۶ و بررسی جزئیات/خطای JavaScript. نصب با اختلاف محدود چهار فایل مشترک، کنترل هش و بکاپ نسخهٔ واقعی سرور.

اصلاح ظاهر ۱۴۰۵/۰۷/۱۸: جدول پایین از صفحه حذف شد (اکسل و چاپ کامل باقی هستند). فیلترها در dialog با دکمه، خلاصهٔ فیلترهای انتخابی روی صفحه، رنگ‌های آبی/سبز/بنفش/کهربایی/صورتی مشترک بین نمودارها، tooltip تعداد/مبلغ/سهم/موجودی روی میله‌ها و بخش‌های SVG حلقه، جزئیات کالا با لمس/کلیک نمودار. اصلاح فقط view و CSS و JS گزارش است؛ محاسبات و مسیرهای قبلی تغییر نکردند.
